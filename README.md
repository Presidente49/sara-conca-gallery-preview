# Sara Conca gallery preview

A public design-review preview of a proposed Sara Conca artist website. The existing Wix website has not been changed.

The GitHub Pages publishing folder is `docs/`. The preview includes original display-size artwork, an opt-in ambient soundtrack, gallery motion, artwork detail pages, and email inquiry links. These review pages remain noindex.
